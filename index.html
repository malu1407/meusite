2. O que são tags semânticas?

R:São tags HTML que indicam o significado e a função do conteúdo, como header,nav,main,section e footer.

3. O HTML é uma linguagem de programação?

R:Não. O HTML é uma linguagem de marcação usada para estruturar o conteúdo de páginas web.
